PART 11 — test/

test/
└── Counter.ts

This contains TypeScript tests.

Now we have two ways to test: 

contracts/Counter.t.sol
          │
          └── Solidity test

test/Counter.ts
          │
          └── TypeScript test

That's a major Hardhat 3 feature.

The official docs explicitly support mixing Solidity tests with TypeScript tests.
