Hardhat 3

Hardhat 3 — Complete Course: From Installation to Verified Testnet Deployment

Yes. We’re going to treat Hardhat itself as the subject, before worrying about building a complicated Solidity application.

The goal is that when you finish this course, commands such as:

hardhat-course — terminal 
$ npx hardhat build
$ npx hardhat test
$ npx hardhat node
$ npx hardhat ignition deploy ...

will not just be commands you memorized. You will know:

what starts → what file Hardhat reads → what plugin runs → what compiler runs → what files are generated → what blockchain is being used → which account signs → what RPC call is made → where the transaction goes → where the contract address comes from → how Etherscan sees it.

This course is specifically for Hardhat 3. As of August 31, 2026, the official Hardhat site lists Hardhat v3.15.0, and its current default templates have moved to Solidity 0.8.34. Hardhat 3 requires Node.js 22.13.0 or later.
