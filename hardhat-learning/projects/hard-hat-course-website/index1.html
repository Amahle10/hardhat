PART 1 — What exactly is Hardhat?

Before installing anything, this distinction matters.

Hardhat is not Ethereum.

Hardhat is not Solidity.

Hardhat is not MetaMask.

Hardhat is not Etherscan.

Hardhat is not your RPC provider.

Hardhat is an Ethereum development environment/toolchain.

The official description is that it provides tooling for writing, testing, debugging and deploying Ethereum software. Hardhat includes or integrates compilation, local blockchain simulation, testing, deployment, coverage and verification functionality.

Think of the system like this:

                    YOUR PROJECT

                         ▼
                    HARDHAT CLI

So Hardhat is the orchestrator.
