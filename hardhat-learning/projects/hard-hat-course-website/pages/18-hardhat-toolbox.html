PART 18 — What is the Hardhat Toolbox?

This package: 

@nomicfoundation/hardhat-toolbox-viem

is essentially a bundle of compatible Hardhat functionality.

Instead of installing every integration one at a time, the toolbox provides the normal development stack.

It incorporates functionality for areas such as:

Viem integration

TypeScript testing

Solidity testing

Hardhat Ignition

network helpers

contract verification

configuration/secrets

assertions

Hardhat's current getting-started project uses the Viem toolbox as its recommended setup.

This is why: 

plugins: [hardhatToolboxViemPlugin]

suddenly gives Hardhat many additional capabilities.
